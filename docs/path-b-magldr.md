# Путь B — MAGLDR: постоянный дуалбут WinMo + postmarketOS

Результат: при включении телефона появляется меню MAGLDR, пункт 1 — Windows Mobile из
NAND, отдельный пункт — postmarketOS с SD-карты.

## Важное предупреждение

Установка MAGLDR **переразмечает NAND и стирает текущую установку Windows Mobile**.
«Сохранение WinMo» здесь означает: сделать бэкап → поставить MAGLDR → залить WinMo
обратно. Без ROM-файла на руках путь не начинать.

Плюс риск: HSPL и прошивка загрузчика — единственные шаги во всей задаче, где телефон
можно окирпичить. Батарея должна быть заряжена >50%, USB-кабель — не хаб, напрямую.

## 0. Бэкап (до всего остального)

- Записать текущую версию радио и SPL: выключить телефон, зажать **Volume Down + Power** →
  экран бутлоадера, переписать все строки (SPL-x.xx, RADIO-x.xx.xx.xx). Сфотографировать.
- Сохранить свой WinMo ROM: либо штатный RUU под вашу версию (`RUU_Leo_HTC_*.exe`,
  внутри `ROM.zip` → `rom.nbh`), либо дамп NAND через `Task29`/`MTTY` до перехода на MAGLDR.
- Скопировать с телефона контакты/SMS/файлы — они не переживут перепрошивку.

## 1. HSPL 2.08

Разлоченный SPL (HardSPL от Cotulla) — обязательное условие для любого стороннего
загрузчика. Ставится с ПК под Windows при подключённом телефоне (ActiveSync /
Windows Mobile Device Center).

Сам по себе HSPL заменяет только загрузчик — Windows Mobile в NAND после него ещё жива
и грузится. Это точка, где можно остановиться и проверить, что телефон в порядке.

## 2. MAGLDR 1.13 (или aMAGLDR 1.13.04)

Два способа:
- через RUU/`DAF.exe` с ПК,
- с SD: положить `magldr.nbh` в корень карты, переименовать в `LEOIMG.nbh`, выключить
  телефон, зажать **Volume Down + Power** — бутлоадер сам найдёт образ и предложит прошить.

После прошивки телефон загружается в меню MAGLDR. WinMo на этом этапе уже нет.

## 3. Вернуть Windows Mobile в NAND

В меню MAGLDR: `4. USB Flasher` → на ПК запустить RUU вашего WinMo-ROM (или прошить
`rom.nbh` тем же способом через SD). После этого пункт `1. Boot WinMo` грузит
Windows Mobile из NAND как раньше.

**Проверьте, что WinMo грузится, прежде чем идти дальше.**

## 4. postmarketOS на SD

Rootfs — как в [пути A](path-a-haret.md), шаг 1: `pmbootstrap install --sdcard=/dev/sdX`.

Ядро для MAGLDR: fastboot тут нет, поэтому `pmbootstrap flasher flash_kernel` не сработает.
Нужно положить `zImage` + `initrd.gz` в каталог на FAT32-разделе SD (традиционно
`\andboot\`) и указать его в MAGLDR: `Services → Boot Settings → AD SD Dir`, затем
грузиться пунктом `Boot AD SD`.

Это **непроверенная часть**: механизм AD SD рассчитан на Android-сборки, и pmOS-образ
может потребовать переупаковки под ожидаемый формат. Вики pmOS про MAGLDR пишет только
«probably works». Если тут упрётесь — рабочая связка остаётся: WinMo из NAND по пункту 1
плюс pmOS через HaRET из-под WinMo (путь A), меню MAGLDR при этом не мешает.

## Откат

Прошить обратно стоковый SPL и WinMo-ROM через RUU. Именно поэтому шаг 0 не пропускать.

## Про cLK

cLK удобнее для pmOS (есть fastboot, вики описывает ровно его), но он размечает NAND
под Android и пункта загрузки Windows Mobile не имеет. Под задачу «не удалять WinMo»
он не подходит.
