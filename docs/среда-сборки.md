# Среда сборки: что где лежит и как поднять заново

Записано 10 сентября, когда WSL начал зависать и встал вопрос о его
переустановке. Всё, что нельзя восстановить командой, лежит в
репозитории; здесь — как этим пользоваться.

## Что где

| Что | Где |
|---|---|
| Проект (этот репозиторий) | `C:\Projects\HTC-HD2-T8585`, из WSL — `/mnt/c/Projects/HTC-HD2-T8585` |
| pmbootstrap | `~/.local/bin/pmbootstrap` |
| Рабочая папка pmbootstrap | `~/.local/var/pmbootstrap` |
| Сборочное окружение (armv7) | `chroot_rootfs_htc-leo` внутри рабочей папки |
| Исходники Rockbox | внутри окружения по `/home/rockbox` |
| Исходники ядра | `~/leo-pmos` |
| Телефон | 192.168.100.235, ключ `out/ssh/openwrt_key` |

Внутри окружения путь `/home/rockbox`, снаружи — тот же каталог по
`~/.local/var/pmbootstrap/chroot_rootfs_htc-leo/home/rockbox`. Снаружи
он под root, поэтому все обращения к нему — через `sudo`.

## Поднять окружение с нуля

```
pip install --user pmbootstrap
pmbootstrap init          # цель: htc-leo, armv7
pmbootstrap chroot -r     # разово, чтобы окружение создалось
```

В окружении нужны: `gcc`, `g++`, `make`, `libsbc-dev`, `sdl2-dev`,
`libx11-dev`, `libxft-dev`, `libxtst-dev`, `fontconfig-dev`,
`freetype-dev`.

## Собрать программу из `out/`

Программы на C (`bta2dp`, `btsdp`, `btscan`, `btpatch`, `l2probe` и
прочие утилиты Bluetooth):

```
sudo cp /mnt/c/Projects/HTC-HD2-T8585/out/ИМЯ.c \
        ~/.local/var/pmbootstrap/chroot_rootfs_htc-leo/tmp/
pmbootstrap -y chroot -r -- gcc -O2 /tmp/ИМЯ.c -o /tmp/ИМЯ -lsbc
```

Программы на C++ (интерфейс: `statusbar`, `keysd`, `btapp`, `shade` и
далее):

```
pmbootstrap -y chroot -r -- g++ -O2 /tmp/ИМЯ.cpp \
    -I/usr/include/freetype2 -lX11 -lXft -lXtst -lfontconfig -o /tmp/ИМЯ
```

`-lsbc` нужен только программам, которые кодируют звук (`bta2dp`, и
`btsdp` — потому что собран из того же основания).

## Положить на телефон

Через `scp` нельзя: на телефоне нет `sftp-server`. Только потоком:

```
ssh -i out/ssh/openwrt_key root@192.168.100.235 "cat > /usr/local/bin/ИМЯ.new"  < ИМЯ
ssh -i out/ssh/openwrt_key root@192.168.100.235 \
    "chmod +x /usr/local/bin/ИМЯ.new && mv /usr/local/bin/ИМЯ.new /usr/local/bin/ИМЯ"
```

Через `.new` и `mv` — потому что заменять работающий файл на месте
нельзя.

## Rockbox

Исходники — официальные, собираются «как приложение» (цель 200,
`sdlapp`) под экран 480x800.

**Порядок обязателен**: правки в исходники вносятся до настройки, иначе
настройка их не увидит.

1. `out/.rbaudio.py`, `out/.rbaudio2.py`, `out/.rbaudio3.py` — вывод
   звука: сначала на плату через `/dev/msm_pcm_out`, затем на колонку
   через канал к `bta2dp`. Правят `firmware/target/hosted/sdl/pcm-sdl.c`.
2. `out/.rbsysfont.py` — крупный системный шрифт (высота строки
   состояния) и память под буферы. Правит `tools/configure`, поэтому
   **строго до настройки**.
3. `out/rockbox-ogg-seek.patch` — без него не играют Vorbis и Opus.
   Накладывается на `lib/rbcodec/metadata/ogg.c`.
4. Настройка: `out/.rbconf.sh` (отвечает на вопросы: цель 200, 480, 800,
   обычная сборка).
5. Сборка: `out/.rbbuild.sh` (`make -j4`, идёт под эмуляцией — долго).

Все скрипты выполняются внутри окружения.

Что кладётся на телефон после сборки:

| Откуда | Куда |
|---|---|
| `build/rockbox` | `/usr/local/bin/rockbox` |
| `build/lib/rbcodec/codecs/*.codec` | `/usr/local/lib/rockbox/codecs/` |

Настройки плеера — `/root/.config/rockbox.org/config.cfg`. Существенные
строки:

```
lang: russian
sbs: крупная
font: /.rockbox/fonts/28-Terminus.fnt
start directory: /root/Music/
touchscreen mode: point
```

`lang` и `sbs` принимают **имя** файла, а не путь: от значения с путём
Rockbox молча сбрасывает все настройки. Файл `out/rockbox-крупная.sbs`
кладётся в `/usr/local/share/rockbox/wps/крупная.sbs`.

## Bluetooth: что важно помнить

- Порт до чипа поднимается на 921600. На 115200 через него пролезало
  ~11 КБ/с — ровно столько, сколько занимает поток A2DP, и звук рвался.
  Заплатка прошивки заливается на 115200, потом переподключение на
  921600; заплатка живёт в чипе, пока с него не снято питание. Вписано
  в `out/btsetup` и `out/bt-fresh`.
- Заплатку не заливать повторно: повторная заливка прошитого чипа вешает
  его намертво. Проверка — по ревизии 0x02f0.
- Wi-Fi и Bluetooth в BCM4329 — один чип. Глушить Wi-Fi через `rfkill`
  бесполезно: вместе с ним умирает Bluetooth.
